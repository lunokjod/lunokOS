The eight faces of this folder are subsets of eight families under the SIL Open Font
License 1.1, and this file is the licence of all of them: the copyright notice of every
family first, then the licence once, because the text is the same for the eight.

**What was changed, and why it has to be said**: a face of this system is read from a
file of at most 128 KB and rasterised by the kernel as it draws (`ui.load_font`, docs/30),
so the originals —from 328 KB to 4.6 MB— do not fit and every file here is a **Modified
Version** in the sense of the licence: it was subset to the codes this system draws
(U+0020..007E, U+00A0..00FF, and the dashes, quotes, bullet and ellipsis at U+2013,
U+2014, U+2018..U+201D, U+2022 and U+2026 — the same set as the DejaVu faces beside them),
the variable families were pinned to their Regular instance (weight 400), hinting and the
layout tables were dropped because this kernel shapes nothing and hints nothing, the ink of
every face was scaled and its baseline put where the ink says so that it sits in the eleven
pixels of a line the system gives it (`--fit-line` of the tool of this project, docs/30), and
the three families whose copyright line reserves a name were **renamed**: Merriweather became
Lunok Serif, IBM Plex Sans became Lunok Sans and OpenDyslexic became Lunok Readable, as
section 3 of the licence requires of a Modified Version. The file names keep the family a
person would look for, and the name table of every file keeps its original copyright.

**Where each one comes from** (downloaded on 11/11, all of them from the project's own
repository through Google Fonts where the family is there):

| File | Family | Source | Note |
|---|---|---|---|
| `literata-latin1.ttf` | Literata | https://github.com/googlefonts/literata | no reserved name |
| `merriweather-latin1.ttf` | Merriweather | https://github.com/EbenSorkin/Merriweather4 | reserved name "Merriweather": the subset is named Lunok Serif |
| `atkinsonhyperlegible-latin1.ttf` | Atkinson Hyperlegible | https://github.com/googlefonts/atkinson-hyperlegible | no reserved name |
| `opendyslexic-latin1.ttf` | OpenDyslexic | https://github.com/antijingoist/opendyslexic | reserved name "OpenDyslexic": the subset is named Lunok Readable, and its CFF outlines were converted to TrueType ones because this kernel reads no CFF |
| `bitter-latin1.ttf` | Bitter | https://github.com/googlefonts/bitter | no reserved name |
| `sourceserif-latin1.ttf` | Source Serif 4 | https://github.com/adobe-fonts/source-serif | no reserved name |
| `inter-latin1.ttf` | Inter | https://github.com/rsms/inter | no reserved name |
| `ibmplexsans-latin1.ttf` | IBM Plex Sans | https://github.com/IBM/plex | reserved name "Plex": the subset is named Lunok Sans |

The other faces of this folder —`dejavusans*.ttf`, `dejavuserif*.ttf` and the bitmap
`dejavusansmono-6x12.lfont`— are DejaVu, and their licence is `LICENCE.txt`, the file
beside this one.
